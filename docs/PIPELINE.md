## 최종 방식

- F 172 + M 75 + R 3 = 250자질을 고정한다.
- 로지스틱은 학습 계정에서 변환과 가중치를 학습한다.
- 이웃 밀도는 함께 평가하는 계정 묶음에서 10번째 이웃까지의 거리를 사용한다.
- 두 점수의 묶음 내 순위를 1:1로 결합한다. k=5·20은 민감도 참고값이다.
- BotSim 로지스틱·RF는 매칭쌍을 유지한 교차검증으로 평가한다. 밀도는 전체 묶음에서 계산한다.
- fox8에서는 BotSim 모형을 고정하고, 임계값 그대로 적용과 fox8 라벨에 의한 임계값만 보정을 구분한다.

## 제외한 것

실패한 동질성 v1.1/v1.2, 폐기한 중심거리 판별기, 다중 모델 재학습판, 이웃 밀도 초기 탐색판, 중복 실행분, OpenRouter API 생성 코드는 실행에 필요하지 않다. 옛 소스·모델을 열어 비교하던 개발용 검사를 제거했다. 대신 최종 연구 산출물에서 만든 고정 기준과 48개 상세 대조를 수행한다.

댓글 통제는 옛 F/M 전용 통제를 따로 실행하지 않고, 같은 댓글 선정 규칙을 분리한 뒤 최종 FMR 통제에서 계산한다. fox8도 옛 실험 JSON에 저장된 계정 목록을 읽지 않고 원자료에서 직접 선정한다. 연구 방법의 변경 경위와 해석 한계는 [결과 요약](RESULTS.md)에 남긴다.
