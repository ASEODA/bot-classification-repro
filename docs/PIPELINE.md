# 실험 순서와 파일 지도

## 연구 질문별 흐름

1. 계정의 글을 정제하고 문장·토큰·품사를 측정한다.
2. 계정마다 F 172개, M 75개, R 3개, 총 250개의 문체 특성을 만든다.
3. 봇·사람 차이를 비교하고 글 분량·댓글 형식·게시판을 **각각** 통제한다.
4. 라벨로 나눈 집단 안에서 계정들의 문체가 얼마나 고른지 비교한다.
5. BotSim에서 배운 로지스틱 점수와 평가 묶음 안의 이웃 밀도 점수를 결합한다.
6. fox8과 저장된 OpenRouter 생성 자료에 적용한다.

## FMR 계산에서 헷갈리기 쉬운 부분

- F: 아포스트로피·대소문자 정규화한 목록 172종. 원카운트 / 비구두점 토큰수, 소수 6자리 반올림.
- M 형태: 복수 값이 있는 문법 범주는 그 범주 합계가 분모. 한 값만 있는 범주는 비구두점 토큰수가 분모. 분모 0은 결측.
- M 품사: 17개 모두 비구두점 토큰수가 분모. `PUNCT`도 같은 규칙.
- R: 평균 문장 길이, 전체 토큰 대비 구두점 비율, 표본표준편차 / 평균 문장 길이. 문장 5개 미만이면 CV 결측.
- 주목 기준 `q ≤ .05`와 `|δ| ≥ .147`은 결과 요약용이다. 판별기에서 250개 중 주목 자질만 뽑아 쓰지 않는다.

## 동질성 검정과 판별기 밀도는 같은 계산이 아니다

**동질성 검정**은 봇·사람 라벨로 집단을 나눈 후 자기 집단 중심까지의 거리로 집단의 퍼짐을 비교한다.

**밀도 점수**는 라벨을 보지 않고 함께 평가하는 계정들 중 10번째 이웃까지의 거리를 잰다. 평가 묶음 안에서 결측을 중앙값으로 채우고 각 자질을 백분위로 바꾼 뒤, 250개 자질의 평균 L1 거리를 사용한다. 거리가 가까울수록 큰 점수를 주기 위해 음수를 취한다.

로지스틱은 학습 자료에서 만든 변환을 고정 적용한다. 두 점수 각각의 **평가 묶음 내부 평균 순위**를 1:1로 결합한 후 0~1로 정규화한다. 동점 처리를 보존하기 위해 순위를 먼저 평균한다.

## 평가 구조

- BotSim: 512쌍을 쌍 단위 5겹으로 분리. 로지스틱·RF는 학습하지 않은 계정의 OOF 점수. 밀도는 전체 1,024계정 묶음에서 계산한다.
- **BotSim 밀도·결합의 문턱 지표는 같은 묶음에서 문턱을 고른 기술값**이다. 이를 전체 중첩 교차검증 성능으로 쓰지 않는다.
- fox8: BotSim 모형 고정 적용. 1,991계정 묶음에서 밀도와 순위를 계산한다. 직접 문턱 적용과 fox8 라벨로 문턱만 5겹 보정한 결과를 구분한다.
- OpenRouter: 새 모델 4종 합동 486계정이 보조 결과. 모델별 묶음과 합동 묶음에서 밀도는 각각 다시 계산한다.

## 중단 후 특정 단계 실행

```bash
.venv/bin/python scripts/reproduce.py step --work work-full \
  --script 11_판별기.py --args --overwrite
```

`raw`를 처음부터 다시 시작하면 시간이 오래 걸린다. 단계 로그와 필수 산출물을 확인하고 필요한 단계부터 실행한다. 전달된 입력·결과의 초기 해시 검사는 `verify`이고, 새 실행 후 결과 비교는 `scripts/check_results.py work-full`이다. **재실행 뒤 원본 해시가 달라지는 것 자체는 정상**이다.
