# 정리본 검증 상태

## 완료

- 과거 실행분·옛 모델·옛 결과 JSON 없이 최종 분석을 실행했다.
- BotSim 원문에서 댓글·politics 코퍼스를 재선정했으며 계정·문서 목록과 필터 집계가 기존과 일치했다.
- 사용률·자질 비교·목록 민감도·FMR 세 통제·귀무 모의 1,000회·동질성·판별기 재학습·OpenRouter·fox8 평가를 다시 계산했다.
- 핵심 수치 대조와 **48개 상세 산출물 대조**가 통과했다. 상세 검사는 모든 계정 카운트·점수, 자질별 통계, 분할, 로지스틱 계수 등을 포함한다.
- FMR 손계산·독립 구현 검사 12개가 통과했다.
- fox8 DB는 원본 NDJSON.gz에서 다시 생성했다.

## 전량 원문 검증 진행 중

BotSim 110,057문서와 fox8 165,532문서의 전량 파싱을 별도 작업폴더에서 실행 중이다. 현재 검증 완료된 분석 재실행과, 아직 진행 중인 전량 파싱을 구분한다. 전량 종료 후 계정별 카운트와 전체 결과를 다시 대조하고 이 기록을 갱신한다.

따라서 **현재 시점에는 원래 연구 폴더를 내려받은 전달본으로 완전히 대체해도 된다고 아직 확정하지 않는다.**

## 범위

- macOS arm64, Python 3.13.7에서 검증한다.
- BotSim 파싱: Stanza 1.14.0 / Torch 2.11.0. fox8·판별: Torch 2.10.0 / NumPy 2.4.3 / SciPy 1.17.1 / scikit-learn 1.8.0.
- 다른 운영체제·CPU에서의 비트 단위 동일성은 미검증이다. 마지막 결과 대조로 확인한다.
- OpenRouter 새 생성·재파싱 및 폐기한 탐색 실험의 재실행은 전달 범위가 아니다.
- 원래 Obsidian 폴더 세 곳은 수정하거나 이동하지 않았다.
