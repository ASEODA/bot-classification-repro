- **핵심 수치 대조 및 48개 상세 산출물 대조 통과.** 계정별 카운트, 문장 길이, 자질별 통계, 분할, 개별 점수, 로지스틱 계수 등을 포함한다. 상세 비교는 실수를 소수점 10자리로 정규화한다.

## 대체 가능한 범위

**최종 연구 재현에는 원래 Obsidian 연구 폴더가 필요하지 않다.** 원래 폴더는 수정하거나 이동하지 않았으며, 연구 메모·폐기한 실험의 이력 보존을 위해 삭제보다 아카이브를 권한다. 전달본은 최종 재현본이지 전체 연구 이력의 백업은 아니다.

- 검증 환경: macOS arm64, Python 3.13.7.
- BotSim 파싱: Stanza 1.14.0 / Torch 2.11.0. fox8·판별: Torch 2.10.0 / NumPy 2.4.3 / SciPy 1.17.1 / scikit-learn 1.8.0.
- 다른 운영체제·CPU에서의 비트 단위 동일성은 미검증이다. 실행 마지막의 결과 대조로 확인한다.
- OpenRouter는 저장된 생성 데이터·측정값을 사용하여 판별 평가를 재실행했다. 새 생성·재파싱 및 폐기한 탐색 실험의 재실행은 전달 범위가 아니다.
