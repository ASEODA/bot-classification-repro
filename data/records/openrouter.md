# 보충 생성 자료

OpenRouter 기록은 저장소의 BotSim·fox8 주 실행 경로와 별개인 보충 자료다. 기존 생성 기록과 측정값을 제공하며, 모델 생성을 다시 실행하거나 보충 분류 실험을 재현하는 실행 코드는 포함하지 않는다.

## 파일과 스키마

| 파일 | 내용 |
|---|---|
| `openrouter-split.json` | 페르소나·사람 계정 배정, 시드, 표집 정의 |
| `../raw/openrouter.jsonl.gz` | 생성 응답 기록과 기록된 모델 식별자 |
| `../raw/openrouter-counts.json.gz` | 계정별 측정값, 대응 부분집합, 민감도 변형 |
| `../raw/openrouter-controls.json.gz` | 사람·원봇·완전모방기 대조군 측정값 |
| `../raw/openrouter-human-examples.jsonl.gz` | 모방에 사용한 예시 원문 |

원자료 파일은 별도로 배포한다. 측정 키, 계정 식별자, 측정값은 원본 스키마를 유지하고, 설명 메타데이터는 배포본 내 경로를 참조한다. 입력 SHA-256은 설명 메타데이터를 정리한 배포 파일이 아니라 원본 단계 자료를 식별한다. 배포 파일의 체크섬은 `../manifest.json`에 있다.

## 기록된 모델

| 슬롯 | 기록된 식별자 |
|---|---|
| MODEL_SLOT_1 | `anthropic/claude-haiku-4.5` |
| MODEL_SLOT_2 | `openai/gpt-6-luna` |
| MODEL_SLOT_3 | `google/gemini-3.5-flash-lite` |
| MODEL_SLOT_4 | `deepseek/deepseek-v4.1-flash` |
| 기준 재생성 모델 | `openai/gpt-4o-mini` |

네 생성 모델 슬롯과 기준 재생성 모델은 동일한 원본 페르소나 배정을 사용한다. 각 슬롯에는 해당 페르소나에 배정된 모델 슬롯과 일치하는 기록만 포함한다. 같은 슬롯 ID의 기록이 여러 개면 마지막 슬롯 기록을 사용하며, 완료 기록이 없는 중단 슬롯은 미완료로 남긴다.

## 페르소나 표집

적격 원봇 562개 중 프롬프트가 있는 첫 응답 슬롯이 10개 이상인 509개를 사용한다. 주제와 슬롯 수 삼분위로 층화하여 배정한다. 시드, 홀수 셀 배분, 속성 가중치, P100 기준 프로필 예외는 분할 파일에 명시되어 있다.

지역은 다음 미국 30개 도시의 고정 목록에서 균등 추출한다. 합성 표집용 목록이다.

## 원문 선정과 측정

공통 선정 규칙은 자기폭로 문장·URL·멘션 제거, 문서당 20자 이상, 계정당 10개 문서 이상, 최대 200개 문서, langid의 계정 단위 영어 판정이다. FMR 측정에는 기록된 Stanza 1.14.0 모델과 Torch 2.10.0을 CPU에서 사용한다. 메타데이터의 모델 경로는 Stanza resources 디렉터리를 기준으로 한 상대 경로다.

사람 대조군은 comment_1·comment_2를 사용한다. 원봇 대조군은 페르소나 원본 계정 509개의 첫 응답에서 복사 슬롯을 제외한다. 원본 기록이 복사로 표시했거나 정규화한 응답과 대상 게시물 제목이 같으면 복사로 본다. 자극문이 없는 원봇 슬롯은 유지한다. 완전모방기 대조군은 보관된 모방 예시를 사용하며 계정 접두사는 MIM_다. 사람 계정의 라벨은 사람, 원봇·완전모방기의 라벨은 봇이다. 분류기 시험에만 쓰는 사람 234개 계정에는 시험 전용 표시가 있다.

생성 응답의 시각은 원 게시물 시각에 지연을 더한다. 지연 구간과 가중치는 BotSim의 `comment_time_function`을 따르며, 가중 `random.choices`로 구간을 고른 뒤 양 끝을 포함한 정수를 추출한다. 슬롯별 시드는 `20260926|slot_id|지연`의 SHA-256 앞 16자리 16진수에서 구하므로 모델이 달라도 같은 슬롯에는 같은 지연이 적용된다. 완전모방기는 계획일을 사용하며 동률이면 파일 순서를 따른다. 이 비교에서는 문서 수가 200개 상한에 도달하지 않아 정렬 규칙이 구성원이 아니라 순서만 바꾼다.

측정값에는 연도·답글 또는 코퍼스별 진단 버킷을 유지한다. 문서별 배열은 슬롯 ID, 시각, 정제 후 글자 수, 문장 수, 비구두점 토큰 수, Tense=Past 수, 전체 Tense 수로 구성된다. 예시 날짜 지표는 예시 시각과 계획일 자정을 비교한다.

## 민감도 변형

- **예시 복사:** 소문자화하고 단어 문자·공백 이외의 문자를 제거한 뒤 공백을 합친다. 주 분석은 동일 원문 또는 `difflib.SequenceMatcher` 유사도 ≥ 0.9를 제외하며, 더 엄격한 민감도 조건은 ≥ 0.8을 제외한다. 길이 차이가 긴 원문의 30%를 넘으면 유사도를 계산하지 않고 0.8 미만으로 분류한다. 정규화 결과가 모두 빈 문자열이면 동일 원문으로 본다. 복사 제외가 없는 조건은 나머지 적격 규칙을 충족하는 슬롯을 모두 유지한다.
- **기준 학습 저자 중첩:** 원래 매칭 학습 표본에서 예시 저자로도 쓰인 사람 106명의 예시를 받은 슬롯을 제외한다. 기존 측정값을 다시 집계하고 최소 문서 수·영어 판정 기준을 재적용한다.
- **대응 부분집합:** 비교 양쪽에서 생성에 성공한 슬롯만 유지한 뒤 계정 적격성을 다시 적용한다. 각 배정 모델을 기준 재생성 모델 및 적격 원봇 슬롯과 비교한다.
- **추가 원문 정제:** 모델 슬롯별로 짝지어진 따옴표와 이름 형태 접두사를 센다. 해당 비율이 1%를 넘으면 접두사 하나와 바깥 따옴표 한 쌍을 제거하고, 원문 정제 규칙을 재적용하여 영향받은 문서를 다시 파싱한다. 정확한 접두사 패턴은 측정 메타데이터에 보존되어 있다.
- **대조군 재측정:** 원봇 대조군은 기준 재생성에 성공한 슬롯으로 제한하고, 완전모방기에서는 중첩 저자 106명의 예시를 제외한다. 원봇 부분집합은 원래 응답 시각, 완전모방기는 계획일을 사용한다.
- **언어 경계 진단:** langid의 정규화 확률 상위 두 값의 차이가 0.05 미만인 적격 계정을 보고한다. 언어 판정에는 이어 붙인 원문을 사용하므로 경계 계정에서는 문서 순서가 결과에 영향을 줄 수 있다.
