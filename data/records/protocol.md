# 평가 프로토콜

2026-10-01에 고정한 fox8 평가 명세를 이 배포본의 파일 구성에 맞추어 정리한 문서다. 원본 문서의 체크섬은 `provenance.json`에 있다.

## 1. 연구 설계

평가 질문은 다음 두 가지다.

1. BotSim 학습 백분위 공간의 최근접 이웃 거리는 로지스틱 분류기에 추가적인 판별 정보를 제공하는가?
2. 그 추가 신호는 집단 간 중심 차이를 제거해도 유지되고, 집단 내 밀집도 차이를 줄이면 감소하는가?

방법은 fox8 개발 집합(995계정)에서 정하고, OpenRouter 보충 실험 계정 486개(생성 봇 252개, 사람 234개)에서도 같은 방향인지 확인했다.

개발 집합에서는 이웃 거리, 군집, 밀도 등 여러 동질성 점수를 비교했다. Ward 군집 점수(군집 수 4)는 중심 차이를 제거하면 AUC가 0.103으로 뒤집혀, 집단 내 밀집이 아니라 위치 정보에 기대는 것으로 나타났다. 최종 명세는 k-최근접 이웃 거리를 사용한다.

로지스틱 가중치, 변환, 주 분석의 이웃 수, 결합 가중치는 평가 전에 고정한다. 확인 라벨은 AUC 계산, 부트스트랩 집단 구분, 집단별 합성 변환, 층화 하위표집에 사용하지만 L의 학습이나 G의 계산에는 사용하지 않는다.

## 2. 입력

- 확인 계정: `split_fox8.json`의 `확인` 필드. 봇 547개와 사람 449개, 총 996개다.
- 사람 자료원: botometer-feedback 116개, gilani-17 87개, midterm-2018 137개, varol-icwsm 109개다.
- 특성표: `../features/fox8.csv.gz`, 절단문 민감도 분석용 `../features/fox8_trunc.csv.gz`.
- 잔존 문구 계정 목록: `excluded_fox8.json`. 자기폭로 문장을 지운 뒤에도 비슷한 문구가 남은 계정이다. 전체 표본 686개이며, 이 중 확인 집합 계정은 348개다.
- 분류기: `../../code/train.py`로 학습한 BotSim 모델. 학습에 fox8 라벨을 사용하지 않는다.

배포 입력의 체크섬은 `../manifest.json`에 있다. 개발·확인 계정 목록은 서로 겹치지 않으며 합치면 fox8 적격 표본 전체가 된다.

## 3. 점수 정의

P는 BotSim 학습 데이터에서 적합한 백분위 함수로 변환한 250개 특성이다.

- L: BotSim 로지스틱 분류기의 봇 확률. 논문의 개별 문체 점수 S_ind다.
- G (k = 10): 평가 집합 안에서 열 번째로 가까운 다른 계정까지의 L1 거리를 250으로 나눈 뒤 음수를 취한 값. 자기 자신은 제외하며 라벨은 사용하지 않는다. 논문의 동질성 점수 S_hom이다.
- S: 집합 내 L과 G의 순위를 [0, 1]로 정규화한 뒤 같은 가중치로 평균한 값.

구현은 평가 집합 자체의 척도를 사용한 이웃 점수(`G_eval`)와 그 결합(`S_eval`)도 비교용으로 보고한다.

## 4. 합성 변환

원 특성값을 변환한 뒤 동일하게 고정된 학습 백분위 변환을 적용한다. 집단 중심은 결측값을 제외한 특성별 중앙값이다.

| 조건 | 변환 |
|---|---|
| W0: 관측값 | 변환하지 않은 특성 |
| W1: 중심 차이 제거 | 각 봇 벡터를 사람 중앙값과 해당 봇의 봇 중앙값 대비 잔차의 합으로 대체. 사람은 유지 |
| W2: 밀집도 차이 축소 | 각 사람 벡터를 사람 중앙값과 무작위로 뽑은 봇 잔차의 합으로 대체. 봇은 유지 |
| W3: 봇 측 잔차 대체 | 각 봇 벡터를 봇 중앙값과 무작위로 뽑은 사람 잔차의 합으로 대체. 비교용으로만 보고 |

W1은 결정적 변환이다. W2는 `np.random.default_rng([20260101, 17, set_id, 2])`, W3는 `[20260101, 17, set_id, 1]`을 사용한다. W2의 추가 추출 4회는 시드 벡터 뒤에 e = 1, 2, 3, 4를 붙인다. 추가 추출은 잔차 표집에 대한 민감도를 보여주며, 기준 판정에는 주 추출을 사용한다.

## 5. 조작 확인

조작 확인 기준을 충족하지 못하면 해당 해석을 유보한다. 수치 결과는 그대로 보고한다.

| 항목 | 기준 | 개발 집합 참고값 |
|---|---|---|
| M1, W2 | P에서 특성별 표준편차 중앙값의 봇·사람 절대 차이 ≤ 0.010, 집단 내 열 번째 이웃 거리 중앙값의 절대 차이 ≤ 0.010 | 0.003; 0.003 |
| M2, W1 | 봇의 특성별 표준편차 중앙값이 W0 대비 변한 정도 ≤ 0.015, L AUC ≤ 0.60 | 0.006; 0.420 |
| M3, W3 | 봇 측 잔차 대체로 줄어든 원래 흩어짐 격차의 비율. 비교용으로만 보고 | 표준편차 52%; 이웃 거리 38% |

`code/evaluation.py`는 위 기준을 그대로 적용한 판정(결과 파일의 `느슨`)과, 소수 셋째 자리 반올림 전후까지 확인하는 보수적 판정(`엄격`)을 함께 기록한다. M2의 보수적 판정은 L AUC의 신뢰구간 상한도 0.60 이하여야 한다.

## 6. 평가 부분집합과 부트스트랩

| 식별자 | 부분집합 | 봇 수; 사람 수 |
|---|---|---|
| 501 | 확인 집합 전체 | 547; 449 |
| A | 목표 봇 비중 50%, 25%, 10%, 5%. 수준별 3회 추출 | 449 / 150 / 50 / 24; 449 |
| 511~514 | 봇 전체와 사람 자료원 하나. 자료원 이름의 사전순 | 547; 116 / 87 / 137 / 109 |
| 521~524 | 봇 전체와 사람 자료원 하나를 제외한 나머지. 같은 순서 | 547; 333 / 362 / 312 / 340 |
| 531 | 절단문 민감도 특성표 | 547; 449 |
| 541 | 잔존 문구 목록에 포함된 확인 계정 348개 제외 | 제외 목록에 따라 결정 |

A의 봇 수는 비중 p를 사용한 `round(449 * p / (1 - p))`다. 정렬한 확인 봇 ID에서 비복원 추출하며 시드는 `[20260101, 17, 2, 100*p, s]`, s = 0, 1, 2다.

AUC와 대응 점수 차이에는 집단별 부트스트랩 2,000회와 백분위 95% 구간을 사용한다. 사람·봇의 부트스트랩 키는 각각 `(17, set_id, 1)`, `(17, set_id, 2)`다. A에서는 `(17, 600 + 100*p, s, 1)`, `(17, 600 + 100*p, s, 2)`를 사용한다. `common.boot_counts`는 각 키 앞에 20260926을 붙인다. 집단 안에 추가 층은 두지 않는다.

점수와 이웃 구조는 부분집합별로 한 번 계산하고 부트스트랩 반복 중에는 고정한다. 따라서 구간은 해당 부분집합과 점수 구성에 조건부인 불확실성을 나타낸다.

## 7. 판정 기준

판정 기준은 개발 집합 결과를 바탕으로 확인 집합 평가 전에 정했다. 표의 개발 집합 값은 참고값이다.

| 기준 | 정의 | 개발 집합 참고값 |
|---|---|---|
| P1 | 501에서 S − L의 95% 구간 하한 > 0 | +0.049 [0.036, 0.063] |
| P2 | 501/W1에서 G AUC의 95% 구간 하한 ≥ 0.90 | 0.989 [0.983, 0.994]; L 0.420 |
| P3 | 501/W2에서 G AUC의 95% 구간 상한 ≤ 0.75, 점추정 차이 G AUC(W0) − G AUC(W2) ≥ 0.20 | 0.598 [0.564, 0.633]; 차이 0.387; 추가 추출 0.487~0.570 |
| P4 | 수준별 3회 평균을 사용하여, 봇 비중 10%·5%의 평균 S − L에서 50%의 평균 S − L을 뺀 값 ≤ +0.005 | −0.015 |
| P5 | 50%·25%의 6회 모두 S − L의 구간 하한이 양수이고, 5%에서는 3회 중 적어도 1회 구간 하한이 0 이하 | 6/6; 1/3 |
| P6 | 자료원 하나씩 제외한 4개 부분집합 모두, 단일 자료원 부분집합 최소 3개에서 S − L의 구간 하한이 양수 | 4/4, 최솟값 +0.030; 4/4, 최솟값 +0.011 |
| P7 | 531과 541 각각에서 S − L의 구간 하한이 양수이고 P2·P3 충족 | 531: +0.049, W1 0.990, W2 0.563; 541: +0.045, W1 0.980, W2 0.403 |
| P8 | 501에서 S − S_eval의 점추정값 > 0. 비교용으로만 보고 | +0.013 [0.007, 0.019] |

## 8. 해석과 산출물

P1은 추가 판별력의 근거다. P2·P3과 M1·M2까지 충족하면 합성 분석은 추가 신호가 중심 차이만이 아니라 집단 내 밀집과도 관련됨을 뒷받침한다. 조건을 충족하지 못하면 그에 맞추어 해석을 제한한다. P4부터 P7은 표본 구성과 원문 제외에 대한 민감도를 나타내며, 충족하지 못한 기준도 결과에 포함한다.

합성 변환은 두 점수가 기대는 정보를 가려내며, 봇 계정이 밀집한 원인(생성 모델, 운영자, 시기, 주제)을 구별하지는 않는다.

`../../code/evaluation.py`는 부분집합 점수, 부트스트랩 구간, 합성 조건 결과, 조작 확인 결과를 `results/evaluation.json`에 기록한다. `../../code/run.py`는 `results/summary.md`를 생성하고 계산 결과를 `expected/`와 대조한다.
